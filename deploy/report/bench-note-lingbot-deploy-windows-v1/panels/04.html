固定版本

03
虚拟环境

venv 内 pip 26.2.1；卸载方式就是删掉 F:\AI 这一个目录。

Set-Location F:\AI git clone https://github.com/robbyant/lingbot-world-v2.git git -C .\lingbot-world-v2 rev-parse HEAD # 1895d300…（与预期一致） uv venv .\lingbot-world-v2\.venv --python 3.12 .\lingbot-world-v2\.venv\Scripts\python.exe --version # Python 3.12.13

仓库没有 Windows 安装说明，路径处理和模型加载器都是这次现验的。

命令原文、预期输出与失败处理都写在部署手册里。
