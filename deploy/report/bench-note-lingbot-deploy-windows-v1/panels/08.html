解法：给 cross-attention 加一条 PyTorch 等价回退

causal_fast 的 cross-attention 在源码里硬依赖 flash-attn。
这里不动依赖，在 attention.py 里补一条等价实现。

wan/modules/attention.py（本机实验分支） ① 顶部加 import os ② flash_attention() 开头加分支：没有 flash-attn 时走新实现 ③ attention() 改为委托 flash_attention()（原版回退会静默忽略 padding mask） ④ 文件末尾新增 _attention_impl() 与 _sdpa_varlen_attention() 覆盖 GQA 展开 / 变长 padding mask / causal / 滑动窗口 WAN_ATTENTION_IMPL=auto|flash|sdpa # 装了 flash-attn 仍优先走 flash-attn
